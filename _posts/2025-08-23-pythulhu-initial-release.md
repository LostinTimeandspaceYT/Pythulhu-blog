*Pythulhu v0.1.0 release now available*

<!--more-->

## Pythulhu Version 0.1.0 release

Initial support for Call of Cthulhu & Pulp Cthulhu is now available for testing.
The source code along with the full release notes can be found [here](https://github.com/LostinTimeandspaceYT/pythulhu)

## Features

Below is a list of the major features in this release

### Character Generator

You can create your own characters with the [Pythulhu Character Generator](https://lostintimeandspaceyt.github.io/pythulhu-blog/generator.html)
and selecting your game of choice

### Multiple game/character support

Character-specific information persists between sessions via the *Save & Exit* Button.
Characters can be selected from the intial menu upon device start up. Games currently
supported are *Call of Cthulhu* and *Pulp Cthulhu*

### CircuitPython API

Developers wishing to add support for a game can do so by forking the repo and
creating a pull request. Documentation can be found [here](https://github.com/LostinTimeandspaceYT/pythulhu).
